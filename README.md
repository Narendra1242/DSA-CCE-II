## 5\. Stack and Queue Implementation

### Stack

A stack follows the LIFO (Last In, First Out) principle.

Main operations:

- Push: Inserts an element.
- Pop: Removes the top element.
- Peek: Reads the top element, if implemented.

Programs:

- `stackwitharray.cpp`
- `stackwithlist.cpp`

### Queue

A queue follows the FIFO (First In, First Out) principle.

Main operations:

- Enqueue: Inserts an element.
- Dequeue: Removes an element.
- Front: Identifies the front element, if implemented.

Programs:

- `queuewitharray.cpp`
- `queuewithlist.cpp`

## 6\. Music Playlist Manager

The Music Playlist Manager demonstrates how a doubly linked list can manage song information. It supports adding, deleting, displaying, and navigating between songs. The program simulates playlist operations through a console interface.

## 7\. How to Compile and Run

Install a compatible C++ compiler, such as g++.

Example for the stack program:

``` bash
g++ stackwitharray.cpp -o stack
```

Run on Windows:

``` bash
stack.exe
```

Run on Linux or macOS:

``` bash
./stack
```

Replace the source file name with the program you want to execute. Check each program's input requirements before running it.
